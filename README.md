# Bank Telemarketing Campaign Effectiveness Analyzer

**Author:** Jasveer Singh  
**Project:** IBM SkillsBuild / AI & Data Science Internship

## Overview
This repository contains an adapted and independently structured analysis of the UCI Bank Marketing dataset. It includes a Jupyter Notebook, project report, and dependency list.

### Files
- `Jasveer Singh_Bank Telemarketing Campaign Effectiveness Analyzer.ipynb` — complete notebook workflow
- `Jasveer Singh_ProjectReport.docx` — project report
- `README.md` — project documentation
- `requirements.txt` — Python dependencies

## Scope
The notebook covers:
1. Dataset loading
2. Data cleaning and duplicate removal
3. Descriptive analytics
4. Diagnostic analysis
5. Feature engineering
6. Random Forest predictive modelling
7. Model evaluation
8. Business interpretation and limitations

## Dataset
The project uses the **Bank Marketing** dataset from the UCI Machine Learning Repository. The dataset concerns direct marketing campaigns conducted by a Portuguese banking institution to predict term-deposit subscriptions.

## Technologies
- Python 3.10+
- Pandas
- NumPy
- Plotly
- Scikit-learn
